📱 Mobile Testing Guide

Complete guide to test video locking functionality on mobile devices

🚀 Open Main App 🧪 Open Test Page

1Open Developer Tools

Open your browser's developer tools using one of these methods:

  • Press F12
  • Press Ctrl + Shift + I (Windows/Linux)
  • Press Cmd + Option + I (Mac)
  • Right-click on the page and select "Inspect"

2Enable Device Simulation

Activate mobile device simulation:

  • Click the device toggle button (📱) in the developer tools toolbar
  • Or press Ctrl + Shift + M (Windows/Linux)
  • Or press Cmd + Shift + M (Mac)

3Select Mobile Device

Choose a mobile device from the dropdown menu:

Recommended devices to test:
  • iPhone 12 Pro - 390x844px
  • iPhone SE - 375x667px (smaller screen)
  • Samsung Galaxy S20 Ultra - 412x915px
  • iPad Air - 820x1180px (tablet)
  • Responsive - Custom dimensions

4Test Video Locking Scenarios

🔒 Scenario 1: User with Zero Credits

Setup: Connect wallet with 0 credits or simulate zero credits

Expected Results:
  • All video cards show lock overlay with 🔒 icon
  • Lock message: "Insufficient credits"
  • Sub-message: "You need at least 1 credit to unlock videos"
  • "Purchase Credits" button is visible and clickable
  • Clicking on locked videos shows purchase modal
  • Videos cannot be played

✅ Scenario 2: User with Credits

Setup: Connect wallet with 1+ credits

Expected Results:
  • Video cards show play button (▶️) instead of lock
  • Videos can be clicked and played
  • Credit count decreases after playing a video
  • When credits reach 0, all videos become locked

🔄 Scenario 3: Credit Depletion

Setup: Start with 1 credit and play a video

Expected Results:
  • After playing, credit count becomes 0
  • All remaining videos become locked immediately
  • Purchase modal appears after 1 second delay
  • Navbar shows updated credit count

5Mobile-Specific UI Tests

Test these mobile-specific aspects:

  • Touch Interactions: Tap videos, buttons, and modals
  • Responsive Layout: Check video grid adapts to screen size
  • Modal Sizing: Purchase modal fits properly on small screens
  • Button Accessibility: All buttons are large enough for touch
  • Text Readability: All text is readable on mobile screens
  • Scroll Behavior: Page scrolls smoothly with locked content

6Test Different Orientations

Rotate the device to test both orientations:

  • Portrait Mode: Default vertical orientation
  • Landscape Mode: Horizontal orientation
  • Check that lock overlays and modals work in both orientations
  • Verify video grid layout adapts properly

⚠️ Important Notes

  • Make sure to test with a real wallet connection for accurate results
  • Check browser console for any JavaScript errors
  • Test on multiple mobile device sizes (small, medium, large)
  • Verify that all interactive elements are touch-friendly
  • Ensure modals and overlays don't break on small screens

7Performance Check

Monitor performance on mobile:

  • Check loading times for video thumbnails
  • Verify smooth animations and transitions
  • Test scroll performance with many locked videos
  • Monitor memory usage in developer tools

🎉 Testing Complete!

If all scenarios work as expected, the video locking functionality is working correctly on mobile devices.
